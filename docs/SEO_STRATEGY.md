# DayCrunch — SEO Strategy

## On-Page SEO

- Unique `<title>` and `<meta description>` per page via Next.js Metadata API
- Product schema (JSON-LD) on product pages
- Semantic HTML (`<header>`, `<main>`, `<nav>`, `<article>`)
- Optimized heading hierarchy (single H1 per page)
- Alt text on all product images
- Internal linking between categories, products, and blog

## Technical SEO

- Dynamic sitemap at `/sitemap.xml`
- Robots.txt blocking admin and API routes
- Canonical URLs via metadata
- Open Graph and Twitter Card tags
- Mobile-first responsive design
- Core Web Vitals optimization (LCP, CLS, INP)
